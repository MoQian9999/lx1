# 桌游集合

> 局域网联机桌游平台 — 打开浏览器就能玩，无需安装任何客户端。

## 零门槛下载（推荐）

无需安装 Node.js！从 [GitHub Releases](https://github.com/MoQian9999/lx1/releases) 下载对应平台的包：

| 平台 | 文件 | 大小 |
|------|------|------|
| 🪟 Windows | `桌游集合-v1.0.0-windows.zip` | ~89 MB |
| 🐧 Linux | `桌游集合-v1.0.0-linux.tar.gz` | ~41 MB |

**使用方法**：解压 → 双击 `桌游集合.exe`（或运行 `./桌游集合`）→ 输入端口号 → 浏览器打开显示的地址。

## 简介

桌游集合是一个轻量级的局域网联机桌游平台。只需一台电脑运行服务器，局域网内其他设备通过浏览器即可加入。平台采用模块化设计，添加新游戏只需复制一个文件夹，无需修改任何现有代码。

**特色：**
- 纯网页，无需安装客户端
- 自定义头像和颜色，个性化显示
- 完善的房间系统，支持多人等待和并行对局
- 模块化游戏设计，扩展新游戏极其简单
- 所有数据存内存，重启即清空，适合临时游玩

## 快速启动

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务器

**Mac / Linux：**
```bash
./start.sh
```

**Windows：**
```
双击 start.bat
```

启动脚本会提示输入端口号，直接回车默认使用 3000。如果端口被占用，会提示重新输入。

启动成功后，终端显示访问地址，例如：`http://192.168.1.100:3000`

### 3. 加入游戏

局域网内其他设备在浏览器中输入终端显示的地址即可进入大厅。登录后即可创建或加入游戏房间。

## 如何添加新游戏

添加新游戏只需 3 步，完全不需要修改任何现有代码：

### 步骤 1：创建游戏文件夹

在 `box/` 目录下新建一个文件夹，文件夹名作为游戏 ID（建议使用英文或拼音），例如 `box/斗地主/`。

### 步骤 2：编写 info.json

在游戏文件夹中创建 `info.json`，填写游戏基本信息：

```json
{
  "name": "斗地主",
  "emoji": "🃏",
  "minPlayers": 3,
  "maxPlayers": 3
}
```

字段说明：
- `name`：游戏中文名，显示在大厅卡片上
- `emoji`：游戏图标，支持 emoji 表情符号
- `minPlayers`：最少需要几个人才能开始游戏
- `maxPlayers`：一个房间最多容纳几个人

### 步骤 3：编写 game.html

创建 `game.html` 作为游戏入口。游戏在 iframe 中运行，通过 `postMessage` 与大厅通信。

**URL 参数：** 大厅在加载游戏时会传递以下 URL 参数：
- `roomId`：房间 ID
- `username`：当前玩家用户名
- `avatarText`：头像文字
- `textColor`：文字颜色
- `borderColor`：边框颜色

**与大厅通信：** 游戏通过 `window.parent.postMessage()` 发送消息，通过 `window.addEventListener("message", ...)` 接收消息。

发送给大厅的消息类型：
- `{ type: "game_ready" }` — 游戏加载完成，可用于接收暂存消息
- `{ type: "game_action", action: "xxx", data: {...} }` — 游戏操作，大厅转发给对手
- `{ type: "play_again", firstTurn: "username" }` — 请求再来一局

接收来自大厅的消息：
- `{ type: "room_update", players, ... }` — 房间玩家变动
- `{ type: "game_start", players, firstTurn }` — 游戏开始
- `{ type: "game_action", action, data, from }` — 对手操作

完整示例请参考 `box/五子棋/` 的实现。

重启服务器后，新游戏会自动出现在大厅卡片中。
