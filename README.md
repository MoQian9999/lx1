# 桌游集合

> 局域网联机桌游平台 — 打开浏览器就能玩，无需安装任何客户端。

## 零门槛下载（推荐）

无需安装 Node.js！从 [GitHub Releases](https://github.com/MoQian9999/lx1/releases) 下载对应平台的包：

| 平台 | 文件 | 大小 |
|------|------|------|
| 🪟 Windows | `桌游集合-v1.0.0-windows.zip` | ~89 MB |
| 🐧 Linux | `桌游集合-v1.0.0-linux.tar.gz` | ~41 MB |

**使用方法**：解压 → 双击 `桌游集合.exe`（或运行 `./桌游集合`）→ 输入端口号 → 浏览器打开显示的地址。

## 简介

桌游集合是一个轻量级的局域网联机桌游平台。只需一台电脑运行服务器，局域网内其他设备通过浏览器即可加入。平台采用模块化设计，添加新游戏只需复制一个文件夹，无需修改任何现有代码。

**特色：**
- 纯网页，无需安装客户端
- 自定义头像和颜色，个性化显示
- 完善的房间系统，支持准备机制和并行对局
- 模块化游戏设计，扩展新游戏极其简单
- 游戏内计时器、悔棋、提醒、认输功能
- 战绩统计，记录胜负场次
- 所有数据存内存，重启即清空，适合临时游玩

**已支持游戏：**

| 游戏 | 人数 | 特色 |
|------|------|------|
| 五子棋 | 2 人 | 15×15 棋盘，落子动画+音效 |
| 黑白棋 | 2 人 | 8×8 棋盘，翻转提示 |
| 象棋 | 2 人 | 完整规则，计时+悔棋+认输 |
| 国际象棋 | 2 人 | 王车易位、吃过路兵、升变、将军检测 |
| 飞行棋 | 2-4 人 | 叠子、飞行、骰子、双人双色、组队模式、可选规则变体 |

## 如何游玩

### 主机（只需要一个人操作）

1. 下载并解压对应平台的包（见上方的下载链接）
2. 双击运行 `桌游集合.exe`（或 `./桌游集合`），输入端口号（直接回车默认 3000）
3. 终端会列出所有可用的局域网地址，例如：

```
本机访问：http://localhost:3000

检测到多个 IP，请根据你的网络选择对应地址：
  http://10.59.210.89:3000  (WLAN)
  http://26.188.144.209:3000  (Radmin VPN)
```

4. 把这个地址告诉其他人

### 加入游戏（其他人无需下载）

其他人在浏览器里输入主机提供的地址，登录后即可创建或加入游戏房间。

> **手机上也能玩**：直接在手机浏览器打开地址，无需安装任何 app。

### 手机热点联机

没有 WiFi 路由器也能玩：

1. 一台手机开启热点
2. 主机电脑连上该热点，启动服务器
3. 其他设备连上同一热点，浏览器输入主机地址即可

终端显示多个 IP 时，选择对应你所用网络的地址（热点通常是 WLAN 地址）。

## 如何添加新游戏

添加新游戏只需 3 步，完全不需要修改任何现有代码：

### 步骤 1：创建游戏文件夹

在 `box/` 目录下新建一个文件夹，文件夹名作为游戏 ID（建议使用中文），例如 `box/斗地主/`。

### 步骤 2：编写 info.json

在游戏文件夹中创建 `info.json`，填写游戏基本信息：

```json
{
  "name": "斗地主",
  "emoji": "🃏",
  "minPlayers": 3,
  "maxPlayers": 3,
  "customReady": false
}
```

字段说明：
- `name`：游戏中文名，显示在大厅卡片上
- `emoji`：游戏图标，支持 emoji 表情符号
- `minPlayers`：最少需要几个人才能开始游戏（全员准备后即可开始）
- `maxPlayers`：一个房间最多容纳几个人
- `customReady`（可选）：`true` 时游戏自行处理赛前阶段（规则选择、角色分配等），`false` 时使用平台默认准备面板

### 步骤 3：编写 game.html / game.css / game.js

创建游戏前端文件。游戏在 iframe 中运行，通过 `postMessage` 与大厅通信。

**URL 参数：** 大厅在加载游戏时会传递以下 URL 参数：
- `roomId`：房间 ID
- `username`：当前玩家用户名
- `avatarText`：头像文字
- `textColor`：文字颜色
- `borderColor`：边框颜色

### 消息协议

**游戏 → 大厅（发送）：**

| 消息类型 | 说明 |
|----------|------|
| `{ type: "game_ready" }` | 游戏加载完成，可接收暂存消息 |
| `{ type: "game_action", action, data }` | 游戏操作，大厅转发给房间内其他玩家 |
| `{ type: "game_over", gameName, result, isDraw, winners? }` | 游戏结束，记录战绩。组队模式时带 `winners` 数组 |
| `{ type: "play_again" }` | 请求再来一局，重置准备状态 |
| `{ type: "set_ready", ready: true/false }` | 仅 customReady 模式使用，报告准备状态 |

**大厅 → 游戏（接收）：**

| 消息类型 | 说明 |
|----------|------|
| `{ type: "room_update", players, ... }` | 房间玩家变动 |
| `{ type: "game_start", players, firstTurn }` | 游戏开始，含所有玩家信息和先手 |
| `{ type: "game_action", action, data, from }` | 其他玩家的操作 |
| `{ type: "ready_update", players }` | 准备状态更新（仅 customReady 模式收到） |

### 完整示例

参考现有游戏实现：
- **五子棋**：最简单的 2 人对战，适合入门参考
- **象棋**：含悔棋、动画、计时器

## 准备系统（Ready System）

平台提供两层准备架构：

### 默认模式（`customReady: false`）

```
加入房间 → 大厅显示房间面板（玩家列表 + 准备状态）
         → 玩家点击"准备"（可取消）
         → 全部准备 → 服务器广播 game_start → 加载游戏 iframe
```

所有现有 2 人游戏（五子棋、黑白棋、象棋、国际象棋）使用此模式，零改动获得准备功能。

### 自定义模式（`customReady: true`）

```
加入房间 → 大厅立即加载游戏 iframe
         → 游戏自行处理赛前阶段（规则设置、角色分配等）
         → 游戏通过 postMessage 报告准备状态
         → 全部准备 → 服务器广播 game_start → 游戏切换到对局界面
```

飞行棋使用此模式，实现赛前规则选择面板。

### 再来一局流程

```
游戏结束 → 玩家点击"再来一局"
         → 大厅销毁游戏 iframe，回到房间视图
         → 所有准备状态重置
         → 玩家重新准备 → game_start → 重新加载 iframe
```
